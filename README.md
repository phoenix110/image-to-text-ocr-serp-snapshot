# Image-to-Text OCR SERP Snapshot

An English-language, US Google organic-results snapshot for `image to text converter`, collected on 2026-09-22.

## Files

- `image-to-text-ocr-serp-snapshot.csv` is the machine-readable row-by-row dataset.
- `comparison.md` is the same comparison as a readable Markdown table with methodology and limitations.

## How to read the dataset

Each row is one result. The `classification` column distinguishes the Android app-store listing from the web-tool pages. “Not stated” means the relevant page did not visibly state that capability or limit during collection.

For a browser-based OCR utility related to this snapshot, see [ClearPixel OCR](https://clearpixelocr.com/).

## Scope and limitations

The collection covers ten results rather than every result that may rank. It records visible page information and page claims; it does not independently test recognition accuracy. Accuracy percentages, language counts, and similar figures are attributed to the corresponding pages. Rankings and pages can change after 2026-09-22.
